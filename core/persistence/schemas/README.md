# Room schema snapshots

Room schema export is configured with KSP (`room.schemaLocation`). The initial version-1 JSON snapshot is generated by the first successful Gradle/KSP build and must be committed from `schemas/1.json` before the first release branch is cut. It is intentionally not fabricated in this archive because the authoring environment could not execute Gradle or the Room processor. Add numbered snapshots and explicit migration tests for every later schema version.
