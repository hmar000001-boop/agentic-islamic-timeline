# Room schema snapshots

Room schema export is configured through KSP (`room.schemaLocation`). The current database source is **schema version 6 with 27 registered entities**. The archive intentionally does not fabricate the Room KSP snapshot (normally placed beneath a database-qualified subdirectory as `6.json`): generate it with the real Room KSP processor on a network-enabled Android Gradle runner, review it against `AppDatabase.kt` and the explicit migrations, and commit it with the migration tests before release.

The source migration chain is explicit and non-destructive: 1→2, 2→3, 3→4, 4→5 and 5→6. Migration 5→6 adds corpus-manifest and embedding-profile fingerprints to dense generation rows and invalidates only derived dense vectors/generations, whose original compatibility cannot be proven. It must preserve every unrelated user/trust/corpus table. Historical snapshots 1.json through 5.json must be retained if/when they are generated. Never replace a prior schema snapshot or add a destructive fallback to make a migration test pass.
