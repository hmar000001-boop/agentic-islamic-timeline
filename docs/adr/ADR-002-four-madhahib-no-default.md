# ADR-002 — Sunni scope, four madhahib, no default school

- Status: accepted
- Date: 2026-11-06

## Decision

The application scope is Sunni. Hanafi, Maliki, Shafi'i and Hanbali positions are representable. No madhhab is selected implicitly; initial preference remains unconfigured until the user explicitly selects a choice or asks for comparison.

## Consequences

Domain and source models carry attribution and school explicitly. Retrieval scores are not religious truth values. Religious functionality remains disabled until relevant sources, licences and qualified review pass their release gates.
